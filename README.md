# Back-End-Development-Pictures

Starter REST API for pictures with Flask and pytest. This is an independently created scaffold, not the official Coursera starter project. Adapt it to the course specifications before submission.

## Run

```bash
python -m pip install -r requirements.txt
python -m pytest -v
python app.py
```

Endpoints: `/health`, `/count`, `/pictures`, `/pictures/<id>` (GET/PUT/DELETE). POST to `/pictures`.
